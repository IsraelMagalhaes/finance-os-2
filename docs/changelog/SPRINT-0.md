# Sprint 0 — Preparação do projeto

## Objetivo

Criar a fundação técnica, documental e de qualidade do Finance OS.

## Entregas

- Projeto React com Vite.
- Tailwind CSS integrado pelo plugin oficial para Vite.
- ESLint em flat config.
- Prettier.
- Husky e lint-staged.
- Estrutura modular de pastas.
- README profissional.
- ADR inicial.
- Página temporária de status da sprint.

## Fora do escopo

- Componentes definitivos do Design System.
- Persistência financeira.
- Dashboard funcional.
- PWA.
- Regras de negócio.
