# ADR-001 — Stack inicial do Finance OS

## Status

Aceita.

## Contexto

O Finance OS precisa começar como uma aplicação local, responsiva e modular, com baixa complexidade operacional e caminho claro de evolução.

## Decisão

Usar React, Vite, Tailwind CSS, JavaScript moderno, ESLint, Prettier e Git como base inicial.

## Consequências

- Desenvolvimento rápido e componentizado.
- Build otimizado para aplicação estática.
- Design system baseado em tokens e utilitários.
- Possibilidade de migração futura para TypeScript.
- Necessidade de disciplina para manter regras de domínio fora dos componentes.
