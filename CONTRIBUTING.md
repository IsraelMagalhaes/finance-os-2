# Contribuindo com o Finance OS

## Fluxo de branches

- `main`: versões estáveis.
- `dev`: integração da sprint.
- `feature/*`: novas funcionalidades.
- `fix/*`: correções.
- `docs/*`: documentação.

## Commits

Use Conventional Commits:

- `feat:` nova funcionalidade.
- `fix:` correção.
- `docs:` documentação.
- `style:` alteração visual sem mudança de regra.
- `refactor:` refatoração.
- `test:` testes.
- `chore:` manutenção.
- `build:` build e dependências.

## Verificação local

Antes de integrar uma alteração, execute:

```bash
npm run check
```
